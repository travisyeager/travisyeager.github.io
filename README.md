# travisyeager.com

Static landing page served by GitHub Pages. Edit `index.html` and push to `main`; the site redeploys automatically. `CNAME` binds the custom domain.

The TV plays a YouTube playlist. Set `PLAYLIST_ID` near the bottom of `index.html` (the part after `list=` in the playlist URL). Until it's set, the TV shows static and "NO SIGNAL".
